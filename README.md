# 굿프랜드유아체육연구소 & 이벤트 — 원페이지 홈페이지

블로그 [blog.naver.com/goodfriend4769](https://blog.naver.com/goodfriend4769) 의 공개 게시글
50편(2020~2026)을 정리해 만든 스크롤 애니메이션 원페이지 사이트.

빌드 도구·프레임워크·외부 라이브러리 **없음**. 파일 3개 + 이미지가 전부다.

## 실행

```bash
python -m http.server 8811 --directory goodfriend-site
```

`http://localhost:8811` 로 접속. 그냥 `index.html` 을 더블클릭해도 되지만,
그 경우 브라우저가 로컬 파일 접근을 막아 영상이 안 나올 수 있다.

## 스크롤 인터랙션

| # | 동작 | 구현 |
|---|---|---|
| 1 | 상단 진행률 바 | scrollY / 문서높이 |
| 2 | 내비 숨김·복귀 | 스크롤 방향 감지 |
| 3 | 요소 등장 (36곳) | IntersectionObserver + stagger |
| 4 | 히어로 영상 확대·흐림 | 스크롤 연동 transform·filter |
| 5 | 키워드 마퀴 | 스크롤 속도에 반응해 가속 |
| 6 | 선언문 단어별 점등 | 스크롤 위치 → 단어 개수 |
| 7 | 숫자 카운트업 | 화면 진입 시 easing |
| 8 | **프로그램 가로 스크롤** | 세로 스크롤 → sticky 구간에서 가로 이동 |
| 9 | 물놀이 배경 패럴랙스 | 섹션 중심 거리 기반 |
| 10 | 연혁 연도 고정 표시 | 화면 중앙에 걸린 항목 추적 |
| 11 | 지역 칩 순차 팝인 | 38ms 간격 |
| 12 | 문의 섹션 물방울 | CSS 애니메이션 |
| 13 | 자석 버튼 | 마우스 추적 (hover 기기만) |
| 14 | 앵커 부드러운 이동 | 고정 내비 높이 보정 |

가로 스크롤 구간(`.rail`)의 높이는 카드 총 너비에서 JS가 계산한다.
폰트·이미지가 늦게 로드되면 카드 크기가 바뀌므로 `document.fonts.ready`,
`ResizeObserver`, `load`, 미디어쿼리 변화에서 각각 다시 잰다.

## 손댈 때 알아둘 것

- **폰트.** `Black Han Sans` 와 `Do Hyeon` 은 물·놀·를·동 등 흔한 글자가
  두부(□)로 나온다. 실측으로 확인했다. `Jua` + `Gothic A1` 은 이 페이지의
  한글 289자를 100% 커버한다. 디스플레이 폰트를 바꾸려면 반드시 렌더링을 확인할 것.
- **모바일에서 가로 레일.** 760px 이하에서는 카드가 세로로 쌓인다.
  이때 JS 가 남긴 인라인 높이를 CSS 가 `height:auto !important` 로 지운다.
  둘 중 하나만 있으면 리사이즈 타이밍에 따라 빈 공간이 생긴다.
- **`prefers-reduced-motion`.** 모든 모션이 꺼지고 가로 레일도 세로로 바뀐다.
- **영상 무음.** `autoplay` 는 `muted` 없이는 브라우저가 막는다. 소리를 넣지 말 것.
