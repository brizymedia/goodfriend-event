## 손댈 때 알아둘 것

- **폰트.** `Black Han Sans` 와 `Do Hyeon` 은 물·놀·를·동 같은 흔한 글자가
  두부(□)로 나온다. 실측으로 확인했다. `Jua` + `Gothic A1` 로 쓸 것.
- **히어로 사진 등장 애니메이션.** `animation-fill-mode:forwards` 가 인라인
  transform 보다 우선해서, 애니메이션이 끝나면 JS 가 `animation:none` 으로
  떼고 패럴랙스를 넘겨받는다. 이 순서를 바꾸면 패럴랙스가 죽는다.
- **모바일에서 가로 레일.** 760px 이하에선 카드가 세로로 쌓인다. 이때 JS 가 남긴
  인라인 높이를 CSS `height:auto !important` 가 지운다. 둘 중 하나만 있으면
  리사이즈 타이밍에 따라 빈 공간이 생긴다.
- **히어로 제목 크기.** 너비(vw)만 보면 1366x768 노트북에서 전화 단추가 접힌다.
  `min(7.4vw, 13vh)` 로 높이도 함께 본다.
- **장비 갤러리는 12장 고정.** 4·3·2 열로 줄이 딱 떨어지게 맞춰 놨다.
  사진을 더하거나 뺄 땐 12의 약수로 맞추는 게 깔끔하다.
